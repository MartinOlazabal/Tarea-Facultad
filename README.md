# 📚 Proyecto de Laboratorio - Base de Datos de Galería en C/C++

## 🏛️ Descripción
Este repositorio contiene las tareas desarrolladas en el laboratorio de la facultad, donde se implementaron diversos conceptos fundamentales de programación en C/C++. El proyecto consiste en una base de datos para una galería de arte, almacenando información sobre:

- 🖼️ Obras expuestas
- 🎨 Artistas y sus exposiciones
- 👥 Visitas de usuarios
- 💙 Obras favoritas de los visitantes
- 📅 Fechas de visitas y exposiciones

## 🛠️ Temas Abordados
Durante el desarrollo del proyecto, se aplicaron los siguientes conceptos:
- Estructuras de datos y algoritmos
- Recursividad
- Manejo de memoria (dinámica y estática)
- Tablas de hash
- Listas y punteros
- Árboles (binarios de búsqueda y generales)
